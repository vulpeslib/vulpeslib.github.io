Vulpes is distributed under the GNU General Public License v3.0 or later (see LICENSE). The libraries below keep their own licences. Except for the adapted SciPy code, they are git submodules in thirdparty/, with the licence in each submodule.

Library Use in Vulpes Licence
Eigen dense linear algebra MPL-2.0
JSON for Modern C++ parameter files MIT
Triangle, modified copy (fork) 2D tessellation, compiled into libvulpes Triangle licence (free for private, research and institutional use, commercial distribution only by arrangement with the author, see thirdparty/triangle/README)
TetGen, fork 3D tessellation, compiled into libvulpes AGPL-3.0-or-later, or a commercial licence from WIAS

GoogleTest tests only BSD-3-Clause
cpplint style checks only BSD-3-Clause

At configure time CMake also downloads LibTorch (BSD-3-Clause), used by the GNN agglomeration. The other dependencies (PETSc, VTK, Boost, GMP, MPI, PT-Scotch, HDF5) come from the system and are not distributed with Vulpes. The Lake Como polygon in examples/data/polygons comes from HydroLAKES (CC BY 4.0; Messager et al., Nature Communications 7: 13603, 2016).

Triangle and TetGen are compiled into libvulpes, so their terms apply to every binary built from Vulpes. Commercial use requires an arrangement with the author of Triangle, and TetGen is used under the AGPL unless a commercial licence is obtained from WIAS.
