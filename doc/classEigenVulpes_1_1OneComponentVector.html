Detailed Description

template<Eigen::Index Idx, typename Scalar_, Eigen::Index Size_>
class EigenVulpes::OneComponentVector< Idx, Scalar_, Size_ >

Eigen expression for a vector with a single non-zero component.

OneComponentVector<Idx, Scalar_, Size_> is a Size_-length column vector that is zero everywhere except at index Idx, which holds a configurable value.

Template Parameters
IdxIndex of the non-zero component (must satisfy 0 <= Idx < Size_).
Scalar_Scalar type of the vector.
Size_Length of the vector.
