Detailed Description

template<typename IndexType>
class vulpes::datastructure::IndexTracker< IndexType >

A class that uses a linked list to keep track of all the indices of a vector that are equal to a certain value. The values are expected to be lower than the size N of the vector (larger values grow the list heads).
