const std::vector< double > & h )
inline

Estimate convergence orders from a sequence of errors and mesh sizes.

For consecutive refinement levels i and i+1, the order is computed as log(err[i] / err[i+1]) / log(h[i] / h[i+1]).

Parameters
errError values, one per refinement level (size >= 1).
hMesh diameters corresponding to each level (same size as err).
Returns
Vector of orders, size = err.size() - 1 (empty for a single level).
Exceptions
std::invalid_argumentif sizes are mismatched or zero.

inline

Print a unified convergence table for one or more named error series.

Each entry in series is a (column_name, error_vector) pair. Convergence orders are computed internally between consecutive refinement levels. Format: scientific notation (3 sig-figs) for errors, fixed (2 d.p.) for orders, "---" on the first row where no order is available.

Parameters
h_vecMesh diameters, one per refinement level.
seriesNamed error series to display. All vectors must match h_vec.
output_dirIf non-empty, the table is also saved as a CSV in this directory (created if it does not exist).
filename_stemBase name of the CSV file without extension.

Evaluate a finite element solution on the vertices of the mesh sub-triangulation used for visualization.

The solution is a la::Vector containing the coefficients of the finite element basis. The basis can be nodal or modal. For each original mesh cell, the solution is evaluated at the vertices of the corresponding VTK subgrid.

Template Parameters
MeshTypeMesh type.
FeSpaceTypeFinite element space type.
Parameters
mesh_exporterSubmesh exporter containing the generated VTK subgrids.
dof_handlerCell-to-dof connectivity.
cell_managerMesh, mappings, and finite element cell data.
solutionCoefficients of the finite element basis.
Returns
CRS map containing one row per exported cell/subgrid. Each row stores the projected values on that subgrid, flattened as vertex_id * block_size + component.
Note
In parallel, only owned cells are projected. The function assumes that the dofs of owned cells are locally owned by the rank, as expected for the DG/modal workflow.
