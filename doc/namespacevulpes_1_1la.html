◆ constantModalCoefficients()

Vector vulpes::la::constantModalCoefficients ( CellManagerType & cell_manager,
const DofHandlerType & dof_handler,
double value = 1.0 )

Coefficients of a constant function in a modal DG space.

The constant is represented exactly by the first basis function of each cell, which is the constant mode of the modal Legendre basis, so the coefficients are computed cell by cell without solving any system. Only the coefficients of the owned cells are set (the others are zero). Typical use: near null space of the Laplacian for algebraic multigrid (see la::SparseMatrix::setNearNullSpace()).

Parameters
cell_managerCell manager of the modal FE space
dof_handlerThe DOF handler
valueThe constant value
Returns
Modal coefficients of the constant function

std::size_t f,
Vector & comp )

Extract one scalar component from a blocked vector into an existing scalar vector (owned entries; ghost entries untouched).

Deduces the block size from the size ratio blocked/scalar and calls VecSetBlockSize before gathering, so this works even when blocked_vec was constructed without an explicit block size (e.g. from a size-only constructor such as an RK stage scratch vector). Symmetric counterpart to addComponent (which uses VecStrideScatter).

Parameters
blocked_vecInput blocked vector
fComponent index to extract
compScalar vector receiving component f
