Detailed Description

template<std::size_t Dim, typename E>
class vulpes::fe::FeExpressionQptsCache< Dim, E >

Values of a coefficient expression (no test or trial function) stored at the quadrature points by precompute(), so that a form evaluates the coefficient once per point instead of once per (basis, point) pair. The stored values are those evaluate() of the wrapped expression returns.
