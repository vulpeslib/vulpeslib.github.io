auto vulpes::mpi::computeChuncks ( int32_t  count,
int32_t  stride = 1 
)
inline

Split count elements into near-equal contiguous chunks, one per rank in the current communicator.

Parameters
countTotal number of elements to split (assumed known identically by every rank).
strideNumber of scalars per element (e.g. vector component count).
Returns
A pair {displacements, counts}, both of size mpi::size(), giving each rank's chunk offset and length (already multiplied by stride), suitable for MPI_*v calls.
