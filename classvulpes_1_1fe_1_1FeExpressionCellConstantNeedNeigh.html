Detailed Description

template<std::size_t Dim, UpdateFlagsType ExtraFlags = UpdateNothing>
class vulpes::fe::FeExpressionCellConstantNeedNeigh< Dim, ExtraFlags >

Class that wraps a function which is cell constant and need the evaluation of neighbours (e.g. penalty coefficient).

Template Parameters
ExtraFlagsUpdate flags added to UpdateNeighborCell, e.g. UpdateNeighborValues when the function reads neighbour values and the form has no neigh(...) leaf.
