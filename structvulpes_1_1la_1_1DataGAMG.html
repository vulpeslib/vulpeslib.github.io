Detailed Description

Options of the PETSc smoothed aggregation algebraic multigrid (PCGAMG).

The smoother is the PETSc default (Chebyshev with Jacobi), which is symmetric and can be used with CG.

Note
For DG discretizations GAMG needs the near null space of the operator (e.g. the constant function for the Laplacian): set it on the matrix with SparseMatrix::setNearNullSpace() before LinearSolver::setOperators().

◆ point_block_smoother

bool vulpes::la::DataGAMG::point_block_smoother = false

Use point-block Jacobi (PCPBJACOBI) in the Chebyshev smoother of every level instead of Jacobi: the diagonal blocks of the size of the matrix block size (e.g. the dofs of a DG cell, see the aij_block_size of SparseMatrix) are inverted exactly. On the coarse levels the block size is the number of near null space vectors.

◆ threshold

double vulpes::la::DataGAMG::threshold = 0.0

Relative threshold to drop the weak edges of the graph used for the aggregation, see PCGAMGSetThreshold(). 0.0 keeps all the nonzero edges, negative values keep also the zero ones. Typical values are 0.0 - 0.08.
