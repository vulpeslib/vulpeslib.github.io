◆ checkOpenBlasThreading()

void vulpes::vutils::checkOpenBlasThreading ( )

Validate the active OpenBLAS thread count.

The function compares the number of threads reported by OpenBLAS with the requested thread budget:

  • OPENBLAS_NUM_THREADS is used when it contains a valid positive integer;
  • otherwise, if OPENBLAS_NUM_THREADS is absent, a valid OMP_NUM_THREADS value is used as the expected budget;
  • if OPENBLAS_NUM_THREADS is present but invalid, no expected OpenBLAS budget can be inferred.
  • if neither OPENBLAS_NUM_THREADS nor OMP_NUM_THREADS is set, no expected budget can be inferred either; a stronger warning is emitted since OpenBLAS's actual thread count is then unpredictable and may silently oversubscribe the machine under MPI.

OpenBLAS is inspected dynamically through libopenblas.so.0 and openblas_get_num_threads(). Diagnostic warnings are emitted if OpenBLAS cannot be inspected or if its active thread count differs from the expected value.

Note
Call this function after PetscInitialize(), when PETSc's BLAS backend is available in the process.
This function is diagnostic only. It does not modify the OpenBLAS thread count.
If PETSc uses another BLAS implementation, OpenBLAS validation is unavailable and a warning is emitted.

◆ configureVtkThreading()

void vulpes::vutils::configureVtkThreading ( )

Configure the VTK SMP thread budget.

The thread budget is read from the OMP_NUM_THREADS environment variable. The value must be a positive integer representable as an int.

If OMP_NUM_THREADS is absent or invalid, Vulpes configures VTK to use one thread per MPI process and emits a warning.

Note
Call this function after MPI initialization and before any VTK parallel operation.
This function configures VTK only. It does not configure PETSc, OpenMP, or the BLAS implementation.
