Detailed Description

template<std::size_t Dim, UpdateFlagsType ExtraFlags = UpdateValues>
class vulpes::fe::FeExpressionFacePointsNeedNeigh< Dim, ExtraFlags >

Class that wraps a face function given by one value per quadrature point, filled by a user function that may read the neighbour's values at the same physical points (fe_values.neighValues()), e.g. a numerical trace built from both sides of the face.

The user function receives the values vector sized to the number of quadrature points. order is the polynomial degree assumed for the values when quadrature rules are chosen. As for any leaf with UpdateNeighborValues, forms using it are integrated only on faces with a neighbour.

Template Parameters
ExtraFlagsUpdate flags the user function needs on both sides, added to UpdateNeighborCell | UpdateNeighborValues (default: shape values).

Compute the polynomial associated to the expression for basis i and j and block bi and bj.

Parameters
fe_valuesFinite element values at quadrature points
jIndex of the trial function basis
iIndex of the test function basis
biBlock index of the trial function
bjBlock index of the test function
Returns
Matrix of polynomials associated to the expression

We use the convention that in the result, each row corresponds to a spatial direction (this extends also to tensors, by unrolling them), while each column corresponds to a addendum of the expression requiring a particular pullback/pushforward transformation. These coefficients are computed by the evaluatePolyCoef method.
